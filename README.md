# NASA Mission Countdown

A simple web app for the SWEN 360L Software Design and Engineering Lab.

## Project Idea
NASA Mission Countdown is a small web page that shows a live countdown to an upcoming space mission launch and displays random space facts. It helps NASA and space education by making launches easy to follow and getting students and the public interested in space exploration.

## Technologies Used
- HTML for the page structure
- CSS for the space-themed styling
- JavaScript for the countdown timer and random fact feature
- Git and GitHub for version control and project management

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open it in a web browser.
4. Watch the countdown, and click the **New Fact** button to see a random space fact.

## Project Management
Tasks are tracked using GitHub Issues, and features are built on separate branches and merged through pull requests.
